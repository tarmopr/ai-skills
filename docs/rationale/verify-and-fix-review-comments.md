# verify-and-fix review-comments.md: rationale

Incidents and reasons moved out of skills/verify-and-fix/review-comments.md to keep it short. Read when changing a rule, not when running the skill.

Why each item is read at `HEAD`: an outdated thread may already be fixed.

Why a bot is never re-requested: a ruleset that wants it re-reviews on push by itself.

Why `--comments` mode reviews only the fix commits: reviewers already saw the rest of the branch.
